# 📊 DatoVivo

**DatoVivo** es una plataforma web que centraliza y visualiza estudios estadísticos, análisis macroeconómicos y tableros de indicadores (dashboards) clave de diversas industrias en **Argentina**.

Nuestro objetivo es democratizar el acceso a datos estratégicos, transformando información compleja en herramientas visuales interactivas que faciliten la toma de decisiones empresariales y financieras.

---

## 🚀 Características Principales

* **Tableros Interactivos:** Dashboards sectoriales para monitorear métricas clave en tiempo real.
* **Análisis Macroeconómico:** Indicadores económicos, tendencias de mercado e informes de coyuntura nacional.
* **Multisectorial:** Cobertura de industrias clave como hotelería, turismo, comercio, finanzas y servicios.
* **Recursos Descargables:** Acceso a reportes en PDF y resúmenes ejecutivos.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript
* **Visualización de Datos:** Power BI / Tableau / Chart.js
* **Alojamiento:** GitHub Pages
